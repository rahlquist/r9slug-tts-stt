r9slug — voice stack

r9slug is a LAN voice node on an NVIDIA RTX 5060 Ti (Blackwell, sm_120). Text-to-speech is a resident, pre-warmed Kokoro-82M service on the dGPU. Speech-to-text is benchmarked locally (Parakeet TDT 0.6B, Moonshine) and can be served from the same box; Hermes currently consumes slug's STT endpoint.
